# Architecture

转换器读取 ComfyUI 保存的工作流 JSON，定位原有 Motion Context 节点组，将实际执行节点复制进原生 Subgraph，再把原节点组与外部画布之间的边界连线重定向到子图宿主。

首段与续写段共用同一个宿主节点：

- 首段通过惰性开关直接输出原始 conditioning、画面和音频。
- 续写段加载上一段 latent，执行 Motion Context，并裁剪继承区间产生的重复画面和音频。
- latent 保存节点不放在条件分支内，因此首段和续写段都会保存当前结果。

转换结束后会检查顶层节点 ID、连线端点、端口索引、子图内部连线和公开端口引用。验证失败时不会静默生成不完整结果。
