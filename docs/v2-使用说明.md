# Motion Context 一键续写 v2

## 主节点

`上一段编号`继续由用户手动填写，行为与 v1 相同。

新增 `允许覆盖已有 latent`：

- 关闭（默认）：如果“本段编号”已经有 latent，工作流会在采样前停止，并显示被占用的文件路径。
- 开启：确认允许覆盖该编号对应的 latent，然后正常生成并覆盖。

## Latent 编号查询

主节点右侧新增独立的 `Latent 编号查询` 节点。节点从上到下依次是：`上传本地视频`、`从下拉框选择视频`、`查询`和`查询结果`。

查询有两种方式：

- 输出目录：在 `从下拉框选择视频` 中选择视频，再点击 `查询`。
- 本地视频：点击 `上传本地视频`，选择电脑上的视频文件。出现“已上传，等待查询”后，再点击 `查询`。

随后：

1. 等待上传和查询完成。
2. 查询结果会显示 Clip 编号和 latent 路径。
3. 根据需要，把该编号手动填入主节点的 `上一段编号`。

查询器不会自动改动主节点参数。

输出目录查询优先读取视频内嵌的 ComfyUI 工作流元数据；读取不到时，会尝试 VHS 同时保存的 PNG 元数据。上传查询只读取视频自身的内嵌元数据。经过剪辑软件重新导出且丢失元数据的视频无法查询，节点会显示明确提示。
