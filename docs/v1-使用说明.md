# 白膜奔跑加强：Motion Context 一键续写 v1

第一版把原工作流中的 Motion Context 加载、应用、去重裁剪、latent 保存和路径拼接封装为一个 ComfyUI 原生子图节点：`Motion Context 一键续写｜首段关，第二段起开`。

## 使用方法

- 生成第一段时：关闭 `续写模式（首段关闭）`。
- 从第二段开始：打开 `续写模式（首段关闭）`，把 `上一段编号` 填为上一段，把 `本段编号` 填为当前段。
- 同一项目的所有片段使用相同的 `项目名称`。
- 常用默认值已经保留：画面继承 22 帧、音频继承 24 帧、24 fps、从尾部匹配。

## 第一版的行为

- 首段直接使用原 conditioning、画面和音频，不加载历史 latent，也不裁剪。
- 首段仍会保存最终 latent，供第二段续写。
- 续写段会加载上一段 latent、应用 Motion Context，并同步裁剪重复画面与音频。
- 当前段最终 latent 在两种模式下都会保存。
- 原工作流未被覆盖，新文件可以单独导入和回退。

## 检查内部结构

该节点使用 ComfyUI 原生 Subgraph。需要排查时，可以双击或通过节点菜单进入子图，内部仍是原来的 Motion Context 节点和路径逻辑。
